# Experiment 3: Catalog Horizontal Scaling

## Objective
To compare the performance of one catalog service instance against two catalog service instances using horizontal scaling.

## Configuration
- API Gateway: Port 5000
- Catalog Instance 1: Port 5003
- Catalog Instance 2: Port 5013
- Load testing tool: k6
- Virtual Users: 20
- Total Requests: 10,000 per test

## Load Distribution Verification

Sent 10 requests through the API Gateway.

| Catalog Instance | Requests Received |
|---|---:|
| Catalog (5003) | 5 |
| Catalog 2 (5013) | 5 |

Result: Round-robin load distribution successfully verified.

## Performance Results

| Metric | One Instance | Two Instances |
|---|---:|---:|
| Average latency | 17.56 ms | 16.97 ms |
| p50 latency | 15.51 ms | 14.69 ms |
| p90 latency | 26.42 ms | 23.01 ms |
| p95 latency | 29.98 ms | 32.64 ms |
| Maximum latency | 55.93 ms | 79.30 ms |
| Throughput | 1126.05 req/s | 1163.65 req/s |
| HTTP 200 checks | 10,000 | 10,000 |

## Observations
1. Both catalog instances received an equal number of requests in the 10-request verification test.
2. Two instances showed slightly better average latency and throughput.
3. Median and p90 latency improved.
4. p95 and maximum latency increased with two instances.

## Preliminary Verdict
Round-robin traffic distribution was verified successfully. However, the performance improvement is inconclusive because the p95 and maximum latency were worse with two instances.

Further validation of the k6 HTTP request failure metric is required before finalizing the experiment.

**Note:** These results are from the recorded test runs and should not be treated as proof of universal performance improvement.
